## Technical Implementation

### Playwright Primitives Used
```javascript
// Proper URL wait with bounded timeout
await authPage.waitForURL(url => url.pathname === '/admin', 
  { waitUntil: 'domcontentloaded', timeout: 15000 });

// Element visibility with bounded timeout
await authPage.locator('aside').waitFor({ state: 'visible', timeout: 5000 });

// Font readiness (no arbitrary sleeps)
await page.evaluate(() => document.fonts.ready);

// Route interception (no external requests)
await context.route('**/*', route => {
  const url = new URL(route.request().url());
  if (url.hostname === 'localhost' || url.hostname === '127.0.0.1') {
    route.continue();
  } else {
    route.abort('blockedbyclient');
  }
});
```
