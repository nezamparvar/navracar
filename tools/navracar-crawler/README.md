# کرالر دسکتاپ ناوراکار (Windows)

ابزاری که روی سیستم شخصی شما (نه سرور) اجرا می‌شود، وارد صفحات دسته‌بندی دابیزل
که مشخص می‌کنید می‌شود، آگهی‌ها را می‌خواند، و یک فایل JSON آماده تحویل می‌دهد که
مستقیم در پنل مدیریت ناوراکار قابل آپلود است (**آگهی‌های دابیزل ← ایمپورت گروهی از
فایل کرالر**).

چون این ابزار از روی سیستم و اینترنت شخصی شما اجرا می‌شود (نه سرور ناوراکار)،
احتمال بلاک‌شدن به‌مراتب کمتر است. سرعت خواندن هم عمداً کند و با تأخیر تصادفی بین
درخواست‌ها تنظیم شده تا شبیه یک کاربر واقعی باشد، نه یک ربات.

## نکتهٔ مهم دربارهٔ نسخهٔ ویندوز (exe)

من (Claude) این کد را روی یک سرور لینوکسی نوشته‌ام و امکان ساخت مستقیم فایل
اجرایی ویندوز (`.exe`) را از این محیط ندارم — ساخت exe باید **روی خود ویندوز**
انجام شود. خبر خوب: این اسکریپت هیچ کتابخانهٔ جانبی نیاز ندارد (فقط پایتون
استاندارد)، بنابراین ساخت exe دو دقیقه‌ای و کاملاً خودکار است — مراحل زیر را
دنبال کنید.

## مرحله ۱: نصب پایتون (فقط یک‌بار)

از [python.org/downloads](https://www.python.org/downloads/) نسخهٔ ویندوز پایتون
(۳.۱۰ به بالا) را نصب کنید. **حتماً** در صفحهٔ اول نصب، تیک
«Add python.exe to PATH» را بزنید.

## مرحله ۲: تنظیم دسته‌های موردنظر

فایل `config.example.json` را کپی کرده و نامش را به `config.json` تغییر دهید.
داخل آن، آدرس صفحهٔ دسته‌بندی/برند دابیزل که می‌خواهید کرال شود را بنویسید — مثلاً:

```json
{
  "categories": [
    { "name": "بنز C-Class", "url": "https://dubai.dubizzle.com/motors/used-cars/mercedes-benz/c-class/" }
  ],
  "max_listings_per_category": 40,
  "max_pages_per_category": 5
}
```

آدرس هر دسته را از خود دابیزل بگیرید: به صفحهٔ برند/مدل موردنظر بروید و آدرس بالای
مرورگر را کپی کنید.

## مرحله ۳: اجرای مستقیم با پایتون (بدون ساخت exe)

اگر فقط می‌خواهید همین حالا داده جمع کنید، نیازی به ساخت exe نیست:

```
cd navracar-crawler
python navracar_crawler.py --config config.json
```

یک فایل مثل `navracar-import-20260812-153000.json` ساخته می‌شود — همین فایل را در
پنل آپلود کنید.

## مرحله ۴ (اختیاری): ساخت فایل اجرایی exe

اگر می‌خواهید بدون نیاز به تایپ دستور، فقط با دوبار-کلیک اجرا شود:

```
pip install pyinstaller
pyinstaller --onefile --name navracar-crawler navracar_crawler.py
```

فایل نهایی در پوشهٔ `dist\navracar-crawler.exe` ساخته می‌شود. آن را کنار
`config.json` کپی کنید و اجرا کنید:

```
navracar-crawler.exe --config config.json
```

(یا فایل `build-windows-exe.bat` پیوست را دابل‌کلیک کنید — همین دو دستور بالا را
خودکار اجرا می‌کند.)

## تنظیمات سرعت/تأخیر (pacing)

در `config.json` بخش `pacing` را می‌توانید تغییر دهید:

| فیلد | پیش‌فرض | توضیح |
|---|---|---|
| `min_delay` / `max_delay` | ۳ تا ۸ ثانیه | تأخیر تصادفی بین هر درخواست |
| `long_pause_every` | هر ۱۵ درخواست | چند درخواست یک‌بار مکث طولانی‌تر بزند |
| `long_pause_seconds` | ۴۵ ثانیه | طول مکث طولانی |

**هرچه این اعداد را بزرگ‌تر کنید، احتمال بلاک‌شدن کمتر و زمان کل کرال بیشتر
می‌شود.** برای شروع همین پیش‌فرض‌ها را نگه دارید.

## دو محدودیت مهم که باید بدانید

1. **منطق استخراج اطلاعات هر آگهی** (قیمت، مشخصات، عکس‌ها) روی یک نمونهٔ واقعی
   آگهی دابیزل تست و تأیید شده — دقیقاً همان نتیجه‌ای را می‌دهد که پارسر سمت سایت
   (`app/Services/DubizzleParser.php`) روی همان صفحه می‌دهد.
2. **منطق پیدا کردن لینک آگهی‌ها از صفحهٔ دسته‌بندی** (تابع
   `extract_listing_links`) روی نمونهٔ واقعی صفحهٔ دسته‌بندی دابیزل تست نشده،
   چون این محیط به dubizzle.com دسترسی شبکه ندارد — فقط بر اساس الگوی شناخته‌شدهٔ
   آدرس آگهی‌ها (که در پارسر تک‌لینکی هم استفاده می‌شود) نوشته شده. **اولین بار که
   اجرا می‌کنید، خروجی ترمینال را نگاه کنید** — اگر نوشت «آگهی جدیدی پیدا نشد»
   ولی می‌دانید آن دسته آگهی دارد، یعنی ساختار صفحهٔ دسته‌بندی دابیزل تغییر کرده و
   الگوی `extract_listing_links` باید به‌روزرسانی شود.

## فرمت خروجی

خروجی یک آرایهٔ JSON از آگهی‌هاست، هر ردیف دقیقاً همان فیلدهایی را دارد که پنل
مدیریت ناوراکار برای ساخت آگهی نیاز دارد (`source_url`, `title_en`, `price_aed`,
`make`, `model`, `model_year`, `images`, و غیره). آگهی‌هایی که قبلاً با همان
`source_url` در سایت ثبت شده باشند، هنگام آپلود در پنل به‌صورت خودکار رد
می‌شوند — پس می‌توانید این ابزار را هر چند وقت یک‌بار دوباره اجرا کنید تا فقط
آگهی‌های جدید اضافه شوند.
